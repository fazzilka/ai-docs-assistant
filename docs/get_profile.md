### GET /api/v1/profile
**Описание**: Эндпоинт для получения профиля пользователя. Используйте этот запрос, чтобы получить данные профиля текущего пользователя: ID, имя, email. Ответ содержит полную информацию о пользователе.
**Параметры**: отсутствуют
**Пример запроса**: как получить профиль пользователя?
**Ответ**:
```json
{"id": 7, "username": "string", "email": "string"}
```
